# ChatGPT 侧边栏行为记录

来源：已登录的 `https://chatgpt.com/`，中文界面，深色主题。结构化尺寸与文字见同目录的 `live-structure.json`。

## 交互模型

- 桌面展开/折叠：点击面板右上角「关闭边栏」或折叠轨道中的 logo 槽位切换；宽度在约 260px 与 59px 之间过渡。
- 折叠轨道：logo、展开按钮、快捷入口、账户头像共享固定的垂直槽位；logo hover 时只在同一槽位交叉淡入展开图标，不新增第二行。
- 分组：点击「已置顶」「项目」「聊天」标题切换 `aria-expanded`；首次观察到的状态分别为 `false / true / true`。
- 分组操作：项目标题提供「整理聊天」「新项目」；聊天标题提供「整理聊天」「新聊天」。操作按钮在 hover/focus 或菜单打开时显示。
- 项目行：每个项目同时有「打开项目首页」和「打开 <项目名> 的项目选项」两个独立尾部操作，尾部操作不改变项目标题的位置。
- 聊天行：选中后保留 active surface；hover/focus 时显示置顶和更多操作，更多菜单包含分享、重命名、置顶、归档、移至项目、删除等动作。
- 账户：点击 `Tom Li Plus` 打开账户菜单；账户菜单支持升级套餐、个性化、个人资料、设置、帮助子菜单、退出登录。
- 搜索：展开面板顶部的「搜索」按钮保持在 40.5px 控件槽位内；搜索属于面板级操作，不应导致 logo 或关闭按钮水平漂移。
- 键盘：新聊天入口显示 `Ctrl + Shift + O` 提示；侧边栏支持 `Ctrl/⌘ + B` 切换。

## 视觉状态

| 状态 | 轨道 | 展开面板 | 关键行为 |
| --- | --- | --- | --- |
| expanded | opacity 0 / pointer-events none | opacity 1 | 内容可滚动，面板宽 260px |
| collapsed | opacity 1 / pointer-events auto | opacity 0 / inert | 外层保留 59px 轨道，主内容不被遮挡 |
| mobile | 桌面结构隐藏 | 由 Sheet 渲染 | 遮罩约 50%，侧边抽屉从左侧进入 |

## 响应式观察

- 1441px：轨道与展开面板同时参与布局，轨道实测 58.5px，展开面板实测 260px。
- 390px：桌面侧边栏不出现在可见 DOM；页面保留顶部菜单入口，点击后通过抽屉展示完整导航。
- 侧边栏内容独立滚动，账户区域保持在底部，不随内容列表一起滚动。

## 复刻约束

- 任何折叠态 logo/toggle 改动都必须保持同一 `40.5px` 槽位。
- 菜单项统一使用 `40.5px` 高度、`15.75px / 22.5px` 字体、`6.75px` 间距，避免不同组件出现 icon baseline 漂移。
- 分组标题是更大的 tertiary 文本（`18px / 27px`），不要复用菜单项的字号。
