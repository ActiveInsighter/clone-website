# RichText, TestimonialTabs, ResponseComparison

Targets: `src/components/evidence/rich-text.tsx`, `testimonial-tabs.tsx`, `response-comparison.tsx`, `editorial-widgets.css`.
Props/types: RichTextBlock, TestimonialTabsProps, ResponseComparisonProps in evidence/types.ts; all normalized source data available under site page article-data.ts.
RichText renders spans with strong/em/code/sup/sub/links safely as React elements, preserves line breaks, does not inject HTML. Accept `blocks: readonly RichTextBlock[]`, optional className. Code blocks have horizontal scrolling and readable mono. Main article text sizing is controlled by page CSS rather than library hard-coding page widths. External hyperlinks use only valid http(s), root relative or # anchors; unsafe URLs stay text.
TestimonialTabs uses shadcn Tabs and Card. Source has3 groups with8/8/5 companies. Company labels 13px tab strip, underline active; horizontally overflow on small widths. Quote card peach #edcbb9, square thin dark borders; 3 metadata areas: QUOTE upper (small uppercase mono), full serif16px/24px quote, bottom COMPANY and AUTHOR in ruled2-column grid. Original quote cards occupy640px reading column with side preview; keep full text and keyboard navigation. No autoplay. Respect reduced motion; opacity180ms on selection. API accepts data, no brand-specific text in library.
ResponseComparison uses shadcn Tabs/Card/Button and normalized3 examples. Labels actual examples from source: see article-data.ts. At desktop two bordered columns, Opus5.5 left / Opus5 right, independently scrollable long outputs, shared prompt displayed. Play/replay control can progressively reveal response content, pause and replay, stop timers on tab change/unmount. Reduced motion reveals instantly. Empty examples renders empty state. Keep complete response content accessible even while visual playback occurs (no fake answers).
No source content embedded in components. Scope styles. No `any`, no unsafe HTML. Export components with named exports. Do not edit shared types/theme. Verify typecheck before finishing.
